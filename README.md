## 技术栈

- 纯静态 HTML / CSS / JS · 无框架依赖
- Tailwind (F.html) / Chart.js / xlsx-js-style (CDN)
- 数据存储：浏览器 `localStorage`（候选人数据已本地脱敏管理）
- 字体：Fraunces / Inter / JetBrains Mono / SF Pro

## 运行

直接用浏览器打开任一 HTML 文件即可，或部署到任意静态托管 (GitHub Pages / Netlify / Vercel)。

```bash
# 本地预览（任选其一）
python3 -m http.server 8080
npx serve .
```
